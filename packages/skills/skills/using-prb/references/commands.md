# prb command groups

Run `prb <command> --help` before using a group. This list is the group name
only.

| Group | What it manages |
| --- | --- |
| `auth` | Login, logout, and status |
| `org` | Organizations the caller can access |
| `user` | People in an organization |
| `framework` | Frameworks |
| `control` | Controls inside a framework |
| `internal-control` | Internal controls |
| `soa` | Statement of applicability |
| `risk` | Risks |
| `risk-analysis` | Risk analysis diagrams |
| `treatment-plan` | Treatment plans |
| `task` | Tasks |
| `document` | Documents |
| `evidence` | Evidence |
| `audit` | Audits |
| `finding` | Findings |
| `asset` | Assets |
| `datum` | Data |
| `third-party` | Vendors |
| `processing-activity` | Processing activities |
| `obligation` | Obligations |
| `rights-request` | Data-subject requests |
| `dpia` | Data protection impact assessments |
| `tia` | Transfer impact assessments |
| `business-function` | Business functions |
| `ai-system` | AI systems |
| `webhook` | Webhook subscriptions |
| `audit-log` | Audit log |
| `connector` | External connectors |
| `scim` | SCIM |
| `device` | Devices |
| `compliance-portal` | Compliance portal |
| `employee-portal` | Employee portal |
| `access-review` | Access reviews |
